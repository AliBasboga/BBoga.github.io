🌍 Flag Guessing Game
Test your memory, learn world flags, and have fun — all in one place!

🎯 About the Project
Flag Guessing Game is an interactive and educational web game that challenges your knowledge of world flags.
A flag appears, and you have to guess which country it belongs to.
It's fun, fast, and a great way to sharpen your memory while learning geography.
